# divelog

スキューバダイビングのログを管理・可視化する Web アプリケーションです。

## 主な機能

- `.zxu` ダイブログのアップロード、GPS 提案の確認、非同期取り込み
- 所有者ごとのダイブログ一覧、詳細、地図、月別ヒートマップ
- 過去ログから最大水深、最低水温、最長潜水時間、エリア別・月別本数を可視化する分析ページ
- Microsoft Foundry の GPT-5.4 によるエリア傾向、利用者傾向、おすすめスポットのオンデマンド生成

分析ページは `/analysis` で提供します。エリアはロケーション名の最初の `:` または `：` より前とし、区切りがないログは「不明」に集計します。最大水深・最低水温・潜水時間の `0` 以下は未記録値として指標から除外しますが、ダイブ本数には含めます。
